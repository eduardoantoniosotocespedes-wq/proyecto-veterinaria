## Sistema de Gestión Veterinaria

¡Bienvenido! Este proyecto es un sistema interactivo diseñado para simular y automatizar las operaciones diarias de una clínica veterinaria, optimizando el control de accesos, el registro de pacientes y la gestión de citas.

## Características Principales

* **Control de Acceso Seguro (Login):** Autenticación de usuarios para proteger la información del sistema según el rol (Administrador, Veterinario, Recepcionista).
* **Gestión de Pacientes (Mascotas):** Registro completo de animales, incluyendo nombre, especie, raza, edad, peso e historial médico detallado.
* **Control de Clientes (Dueños):** Base de datos para asociar a cada mascota con los datos de contacto de su dueño.
* **Agenda de Citas:** Módulo para programar, reprogramar o cancelar consultas médicas, cirugías y baños.
* **Inventario de Medicamentos:** Registro y control de stock de medicinas y productos de la veterinaria.
